# Relay colour-theme evaluator

Interactive comparison of five non-green colour systems on the same app-first Relay layout:

- Midnight
- Cobalt
- Plum
- Graphite
- Clay

Open `index.html` through a local web server. Select a theme above the preview to apply it to the full navigation, workspace, filters, controls, and media grid.

The interface copy is intentionally functional and concise. Promotional headings, taglines, and explanatory subtext are excluded.
